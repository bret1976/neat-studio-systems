# NEAT feature correction — 16 October 2026

The previous implementation passed its basic interaction tests but was incomplete as an experience. The following were identified by re-reading the approved brief, re-inspecting the live Heron site, and sampling the supplied recording at closer intervals. Reference captures: output/reference/reaudit-*, recording-details.jpg. This audit describes actual differences, not an assumption that passing tests establishes visual fidelity.

| Missing or oversimplified feature | Correction |
|---|---|
| Opening had only a hero opacity/clip entrance | Original architectural line-drawing opening, real local asset/font completion, dismissible-by-completion sheet transition, session-only replay prevention, reduced-motion and no-JS fallbacks |
| Context plan started fully drawn | Structural SVG path tracing, progressive detail opacity, centered statement-to-plan transition and existing successive information layers |
| Four-stage workflow changed a rectangle and text | Persistent building plus contextual plan; interpret callout, distinct corridor/door proposals, current/proposed geometry, explicit demo approval, review history, reversible scroll states |
| Mobile stories had no scroll-driven progression | Shorter sticky mobile timelines, with working manual state selection and automatic progression in both scroll directions |
| Assist only exposed one scripted conversation | Four capability modes, separate observation regions, actual current/proposed geometry switches, explicit approval state |
| Control only exposed observations/history | Project overview, criteria toggles, role assignments, revisions/rejection, matching region details, updated counters and decision history |
| Philosophy approval sequence was a static list | Scroll/click-driven observation/recommendation/review/approval sequence with drawing comparison and a separate explicit authorization control |
| Footer was a clean CSS circle | Noise-displaced SVG ink lens, pointer interpolation on the shared GSAP ticker, solid touch/reduced-motion fallback |
| Cursor and keyboard details absent | Fine-pointer drafting cursor/trail/pressed reticle; desktop Escape returns focus to the opened navigation trigger |

Every model action remains an explicitly labeled local demonstration. Scrolling does not approve anything; moving to the last workflow stage without approval shows that a decision is still required. No live BIM adapter, model AI, certified compliance engine or configured email delivery is implied.

Still different: original NEAT drawings and fonts versus Heron's proprietary artwork/typeface; NEAT's longer approved content and extra routes; source uses a custom scroll canvas while NEAT uses native document scrolling with Lenis/CSS sticky. Source agency credits, customer claims, newsletter and awards badge are not reproduced as invented NEAT credentials. Page-swap geometry is not implemented as a Barba clone; Next routing remains native. The raster sketch/render pair is aligned to itself but separate from the editable SVG hero model, as documented in the asset inventory.
